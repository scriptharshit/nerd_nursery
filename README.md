# nerd_nursery
For Haxbaby baby's first hackathon

Blu’s Academic Arcade is a chaotic, retro-internet dashboard built for haX.baby’s Baby's First Website Hackathon. It features Blu, a brilliantly sassy 2D animated character who aggressively judges your lifestyle, reading choices, and musical abilities in real time.
The website includes a dynamic Web Audio synth piano, a cozy library panel with a custom drag-and-drop PDF reader, an automated study planner, and a built-in retro arcade cabinet minigame where you must steer Blu’s brain to catch A+ grades while dodging failure. Built purely with HTML, CSS, and vanilla JavaScript, it features a chunky 90s aesthetic, an infinite blueprint grid pattern, and an all-important global mute switch for seamless audio accessibility control.
